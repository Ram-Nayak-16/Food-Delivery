# Local Setup Instructions for CrazyBite Food Delivery App

This project is configured to run locally from scratch.

## Quick Launch
Run `start-all.bat` or execute in PowerShell:
```powershell
.\start-all.bat
```

## Services:
- **Backend Server**: http://localhost:4000
- **Frontend Storefront**: http://localhost:5173
- **Admin Dashboard**: http://localhost:5174
